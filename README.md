# 简历 · Markdown 简历编辑器

在线使用：<https://web-abin.github.io/md-resume/>

本地运行的简历工具 MVP。左侧编写 Markdown，右侧实时预览，内容和排版设置保存在当前浏览器的 localStorage 中。无需登录、无需 AI API Key，不上传简历。

## 启动

需要 Node.js 22.13 或更高版本。首次运行安装依赖：

```bash
npm install
npm run dev
```

打开终端中显示的本地地址（默认 http://localhost:3000）。macOS 也可双击 `启动.command`。不要直接打开源代码文件；这是需要本地服务的 Web 应用。

## 已实现

- Markdown 实时预览，支持标题、列表、加粗、链接、引用、代码和表格；编辑区与预览区各自独立纵向滚动。
- 三套模板：清简、秩序、书卷；五种主题色。
- 字号、行距、页边距实时调整；自动适应预览宽度和手动缩放。
- 「恢复推荐」将主题颜色、字号、行距、页边距恢复为松石绿 / 15 px / 1.6 / 17 mm，保留当前模板和正文。
- 草稿及排版设置自动保存；点击编辑区右上角「导入 Markdown」选择 `.md`、`.markdown`、`.txt`，确认替换后立即渲染，保留模板和排版设置。支持导出 Markdown。
- 恢复示例和导入替换之前二次确认。
- 本地中文字体与 A4 清晰文字 PDF，直接下载，无需系统打印设置；长文档按文字行与标题分组分页。
- 预览缩放旁的「排版设置」按钮可展开 / 收起侧栏，默认收起；收起不会清除设置。
- 小屏幕编辑 / 预览切换，键盘可操作的语法帮助窗口。
- HTML 白名单过滤，禁止脚本、内联样式、图片及嵌入资源。

## 我的简历与版本保存

标题右侧「我的简历」打开本地版本列表。右上角「保存」每次新增一份快照，记录 Markdown 原文、模板、主题色、正文字号、行间距和页边距。标题从 Markdown 一级标题提取，列表按保存顺序倒序排列并显示时间。

点击列表项会替换编辑器内容并恢复该版本的全部排版参数；继续编辑不会改写旧版本。删除需在列表内确认，且不会清空当前编辑器。草稿仍自动保存，状态移到编辑区底部；未手动保存的草稿不会列为版本。

版本存储键为 `jianli-library-v1`，与自动草稿分开。保存或删除遇到存储异常会提示失败，不覆盖既有版本。数据仅属于当前浏览器、域名和端口；清理浏览器数据会丢失记录，不支持跨设备同步。

## 简历格式

```markdown
# 姓名 · 求职岗位
城市 ｜ 手机 ｜ 邮箱

## 工作经历
### 公司名称 · 职位 || 2023.06 — 至今
- **成果关键词**：描述工作内容、方法和真实的量化成果。

## 教育经历
### 大学 · 专业 / 学位 || 2019.09 — 2023.06
```

` || `（两侧有空格）在标题或独立段落中把内容分为左侧说明和右侧日期。不支持多个分隔符或在同一段中放置多个左右对齐行。

## PDF 导出

点击「导出 PDF」直接生成文件。若浏览器未自动保存，可点击右下角「下载 PDF」。

- 默认是**真正的矢量文字 PDF**：中文字形以 TrueType 子集字体嵌入，放大保持清晰，支持选择、复制和搜索。
- 模板背景、边框和分隔线也使用矢量绘制。字体和布局来自同一份预览内容，不是整页截图。
- 导出按 A4 原始尺寸计算，预览缩放、窗口大小、侧栏显示状态和暗色模式不会影响纸张颜色或导出尺寸。
- 按文字行和标题分组分页，并过滤当前页外的文字，避免复制或搜索时跨页重复。
- 中文字体覆盖范围与项目使用的思源字体一致。部分阅读器的复制顺序可能受加粗与链接等独立文本片段影响；特殊符号和复杂 HTML 应在导出后检查。
- 顶部打印机按钮仍可调用系统打印；这一模式的最终分页由浏览器控制。

实时预览按 A4（210 × 297mm）显示独立纸张，页间留 28px 间隔并显示页码。与 PDF 导出共用内容测量和分页规则，每页重复保留设定的页边距；字号、行距、页边距或内容改变后自动重新分页。极长段落、列表项或表格行允许跨页，避免遗漏内容。

## 界面与暗色模式

顶部月亮 / 太阳按钮切换亮色与暗色模式。首次跟随系统设置，选择后保存在当前浏览器的 `resume-ui-theme`。界面文字已放大：正文编辑区为 14px，主要按钮为 14px，常用设置标签为 13px。简历本身的字号仍由排版设置控制。

暗色模式仅改变界面，不改变简历白色纸张或 PDF。预览左下角的保留中文与排版提示已移除。

## 本地数据与限制

- 浏览器存储键：`jianli-markdown-v1`。每个浏览器、域名和端口分别保存一份草稿；切换端口可能看不到此前草稿。
- 清理浏览器数据或使用无痕窗口可能丢失草稿，请定期导出 Markdown 备份。
- Markdown 导出仅保存内容，不包含模板设置。MVP 不含账号、云同步、照片上传、AI 润色、Word 导出或手动分页。
- 文本最多 100,000 字符，导入文件最多 300 KB；示例人物与经历均为虚构。
- 项目通过 GitHub Actions 自动构建并部署到 GitHub Pages。网页数据仍只保存在当前浏览器中，不会上传到服务器。

## 开发与验证

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

技术栈：React、TypeScript、Vinext / Vite、Marked、DOMPurify、html2canvas-pro、jsPDF。图标使用 Lucide（ISC License）。保留 Sites 初始化结构，便于后续部署；本地简历编辑功能不依赖账号或远程数据库。

自动化测试覆盖 Markdown 语义、左右对齐语法、安全过滤、设置校验和文件名处理。已在实际浏览器验证侧栏开关，并生成、渲染检查三套模板及多页中文 PDF。打印文字版的最终分页仍需自行检查。

本轮已在浏览器验证桌面与小屏幕的独立滚动、60 条经历的 Markdown 文件导入，以及恢复推荐时保留正文与模板。最终 PDF 分页仍以系统打印预览为准。

字体授权文件保存在 `public/fonts/*-LICENSE.txt`。自动化测试目前共 11 项，新增分页边界、标题与后文保持连接及超长内容完整性检查。

PDF 固定字重字体位于 `public/fonts/pdf/`，由现有 Fontsource 中文字体转换、合并生成；SIL OFL 授权文件在 `public/fonts/`。字体派生名称为 Resume Sans SC / Resume Serif SC，常规与加粗字重为 400 / 700。

推荐正文为 15px（11.25pt）、1.6 倍行距和 17mm 页边距。参考 Tech Interview Handbook 的技术简历可读性建议与 Stanford 的 10–12pt 正文范围，结合中文字符密度调整；已有保存版本保留原参数，可点击「恢复推荐」应用新参数。

## 撤回与局部字号

内容编辑工具栏支持最多五步撤回，快捷键为 macOS Command+Z，Windows/Linux Ctrl+Z；按钮与快捷键共用记录。连续输入合并为一步，格式修改、导入、恢复版本和整体排版也可撤回；刷新页面会清空撤回记录，不影响草稿及手动版本保存。

选中文字后，在「字号」下拉框选择 11–24px 的整数字号，或 26、28、30、32、34、36、38px。使用受限的 `<span class="resume-size-18">文字</span>` 标记保存在 Markdown 中，预览、分页、PDF 和保存的版本均保留效果；不开放任意 style 样式。其他 Markdown 阅读器可能不支持此扩展字号。
